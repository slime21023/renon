== 語意化提示框 (Admonitions)

AsciiDoc 原生支援五種語意等級的提示區塊。Renon 將它們轉換為具備獨立 SVG 圖示與深淺色主題變數的 `<aside class="re-callout">` 元件：

.AsciiDoc 提示框撰寫語法（可點擊右上角複製）
[source,asciidoc]
....
NOTE: 這是一則 **提示 (Note)** 區塊，適合用來補充背景知識或額外說明。

TIP: 這是一則 **技巧 (Tip)** 區塊，適合分享最佳實踐、快捷操作或效能優化建議。

[IMPORTANT]
.自訂提示框標題也是支援的！
====
當您需要包含多個段落或清單時，可以使用 `====` 區塊語法並加上 `.自訂標題`：

* 支援在提示框內嵌入清單與 `行內程式碼`。
* 自動根據 `[data-theme="dark"]` 切換柔和的深色背景與高對比邊框。
====

== 程式碼高亮、行號與重點行標記 (A1)

在 `[source,<lang>]` 區塊加上 `linenums` 即可顯示行號，搭配 `highlight="2,5-7"` 可標記單行或連續區間重點行，且複製按鈕只會複製純程式碼（不包含行號）：

.AsciiDoc 程式碼區塊語法（可點擊右上角複製）
[source,asciidoc]
....
.src/lib/example-converter.js（含行號與第 2、5~7 行高亮）
[source,javascript,linenums,highlight="2,5-7"]
----
import Asciidoctor from "@asciidoctor/core";
import hljs from "highlight.js";

export function highlightCode(source, lang = "javascript") {
  if (hljs.getLanguage(lang)) {
    return hljs.highlight(source, { language: lang }).value;
  }
  return source;
}
----
....

**實際渲染效果：**

.src/lib/example-converter.js（含行號與第 2、5~7 行高亮）
[source,javascript,linenums,highlight="2,5-7"]
----
import Asciidoctor from "@asciidoctor/core";
import hljs from "highlight.js";

export function highlightCode(source, lang = "javascript") {
  if (hljs.getLanguage(lang)) {
    return hljs.highlight(source, { language: lang }).value;
  }
  return source;
}
----

== 互動式分頁區塊 (`<re-tabs>`) (A2)

.AsciiDoc 互動式分頁語法（可點擊右上角複製）

....

----
bun install
bun run dev

npm::
+
[source,bash]
----

npm run dev
----

pnpm run dev
----

== KaTeX 數學公式建置期預渲染 (A4)

在文件標頭宣告 `:stem: latexmath` 後，即可撰寫行內公式如質能等價公式 latexmath:[E = mc^2] 或時間複雜度 latexmath:[\mathcal{O}(n \log n)]，亦可使用 `[stem]` 撰寫獨立區塊公式（建置期直接轉為靜態 HTML+MathML，零客戶端 JS 負擔）：

.AsciiDoc 數學公式語法（可點擊右上角複製）
[source,asciidoc]
....
= 文章標題
:stem: latexmath

行內公式：質能等價公式 latexmath:[E = mc^2] 或時間複雜度 latexmath:[\mathcal{O}(n \log n)]。

.高斯積分與歐拉恆等式
[stem]
++++
\int_{-\infty}^{\infty} e^{-x^2} \, dx = \sqrt{\pi} \quad \text{and} \quad e^{i\pi} + 1 = 0
++++
....

**實際渲染效果：**

.高斯積分與歐拉恆等式
[stem]
++++
\int_{-\infty}^{\infty} e^{-x^2} \, dx = \sqrt{\pi} \quad \text{and} \quad e^{i\pi} + 1 = 0
++++

== 表格、鍵盤快捷鍵與定義清單

=== 結構化資料表格

.AsciiDoc 表格與鍵盤巨集語法（可點擊右上角複製）
[source,asciidoc]
....
[cols="1,1,2", options="header"]
|===
| 語法特性 | Markdown 原生支援 | AsciiDoc 原生支援

| 鍵盤快捷鍵巨集
| 需手寫 `<kbd>`
| 原生內建 kbd:[Ctrl+Shift+P] 巨集
|===
....

**實際渲染效果：**

[cols="1,1,2", options="header"]
|===
| 語法特性 | Markdown 原生支援 | AsciiDoc 原生支援

| 跨欄 / 跨列表格
| 需手寫 HTML `<table>`
| 原生支援 `2+^{vbar}` 等格線合併語法

| 五級語意提示框
| 無標準語法
| 原生內建 `NOTE` / `TIP` / `IMPORTANT` / `WARNING` / `CAUTION`

| 外部檔案引入
| 不支援
| 原生內建 `include::path[]`（可指定行號區間或 tag）

| 鍵盤與按鈕巨集
| 需手寫 `<kbd>`
| 原生內建 kbd:[Ctrl+Shift+P] 巨集（已預設開啟 `:experimental:`）
|===
